About this project
Built from scratch to support Security+ exam preparation

This suite was designed and built entirely in HTML, CSS, and vanilla JavaScript — no frameworks, no dependencies, no build tools. Every tool runs as a single self-contained HTML file that works offline.

The four mock exams contain 360 unique questions with zero overlap. Each exam includes multiple choice questions, drag-and-drop matching, performance-based questions (firewall configuration, network zone placement, log analysis, ACL permissions, wireless setup, PKI certificate review, and incident response ordering), and definition questions.

All tools log session results to the browser's localStorage, which the dashboard reads to track progress over time — building a cross-tool picture of exam readiness by domain.
