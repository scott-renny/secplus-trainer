Every trainer and exam automatically logs your score to the browser's localStorage when you finish a session

About this project
Built from scratch to support Security+ SY0-701 exam preparation
This suite was designed and built entirely in HTML, CSS, and vanilla JavaScript with no frameworks, no build tools, and no dependencies. Every tool runs as a single self-contained HTML file that works completely offline once downloaded. All files can be placed in the same folder and opened directly in any modern browser.
The four mock exams contain 360 unique questions with zero overlap across any pair. Each exam includes multiple choice, drag and drop matching, performance-based questions covering firewall configuration, network zone placement, log analysis, ACL permissions, wireless setup, PKI certificate review, and incident response sequencing. Every answer is randomised on each attempt.
