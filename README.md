A browser-based study suite created to reinforce the concepts, terminology, and practical reasoning covered by the CompTIA Security+ certification objectives.

## Overview

Security+ Trainer is a collection of self-contained HTML learning tools that run locally without a server, account, or internet connection. It includes focused domain trainers, acronym and port exercises, performance-based question practice, and four mock examinations.

## Included Learning Tools

- Security+ study dashboard
- Domain-focused concept trainers
- Acronym and definition practice
- Common ports and protocols trainer
- Performance-based question trainer
- Four full mock examinations
- Exercises for cryptography, threats, architecture, identity, incident response, risk, and security programs

## Getting Started

1. Download or clone the repository.
2. Open index.html in a modern web browser.
3. Select a trainer or mock examination from the dashboard.

No installation, build process, or external dependency is required.

## Repository Structure

| File group | Purpose |
|---|---|
| index.html | Main entry point |
| secplus_dashboard.html | Study dashboard |
| secplus_all_domains files | Cross-domain trainers and mock exams |
| secplus_d1 through secplus_d5 files | Domain-focused learning tools |

## Learning Objectives

The project supports practice across the major Security+ knowledge areas, including general security concepts, threats and vulnerabilities, security architecture, security operations, and security program management.

> [!NOTE]
> This is an independent study project. It is not affiliated with or endorsed by CompTIA and does not reproduce official examination questions.
